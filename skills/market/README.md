# Market catalog

This directory is the `market` category in the standard Agent Skills catalog layout. Each child directory contains one independently discoverable `SKILL.md` and any files that belong to that skill.

Install the complete catalog:

```bash
npx skills add laze44/oh-my-zz --all
```

Install one entry:

```bash
npx skills add laze44/oh-my-zz --skill idea-refine
```
